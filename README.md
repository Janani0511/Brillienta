🌟 Brillienta — Brilliance in Every Student

🌍 Overview
Brillienta is an educational website built to showcase the brilliance in every student.
It’s designed with simplicity, creativity, and elegance using Bootstrap 5, emphasizing both learning and inspiration.

Throughout the development process, I faced several challenges — balancing color ratios, ensuring carousel functionality, and refining the visual design to achieve harmony between content and creativity.

With patience and curiosity, I explored Bootstrap documentation, sought help from ChatGPT and Bing for code snippets and design suggestions, and learned to blend aesthetics with function.

This project took a full day of dedicated effort, where each bug fixed and layout refined brought me closer to understanding the art of front-end development.

By the end of this journey, I gained deeper insight into HTML, CSS, and Bootstrap, along with an eye for detail — from choosing the right shades of gold to aligning every section perfectly. ✨

💻 Technologies Used

HTML5 – For building the structure and layout of the web pages

CSS3 – For custom styling, alignment, and visual enhancements

Bootstrap 5 – For responsive, mobile-friendly design and prebuilt UI components

ChatGPT & Bing – For assistance, creative inputs, and code troubleshooting

🌟 Features

🎓 Student-Centric Design – Built around the idea of celebrating each learner’s brilliance

🖼️ Dynamic Carousel – Showcases motivational learning slides with inspiring captions

📱 Fully Responsive Layout – Works seamlessly on mobile, tablet, and desktop screens

🎨 Elegant Color Palette – A blend of gold and dark tones for a professional, modern look

💫 Interactive Sections – Highlights student experiences, testimonials, and achievements

🧭 Smooth Navigation Bar – Ensures intuitive and organized browsing
