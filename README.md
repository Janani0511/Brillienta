## 🌍 Overview
**Brillienta** is a modern educational website built to showcase the brilliance in every student.  
Designed with **simplicity**, **creativity**, and **responsiveness**, it aims to inspire learners through elegant design and intuitive navigation.

Built using **Bootstrap 5**, **HTML**, and **CSS**, the project demonstrates the harmony between design and function.  
It was completed within **1 day** of dedicated effort and exploration.

---

## 🧠 Challenges Faced
During the development process, I encountered and overcame several challenges:
- ⚙️ Balancing color ratios and maintaining aesthetic consistency  
- 🌀 Carousel setup and ensuring smooth transitions  
- 📐 Spacing, alignment, and responsive design across screen sizes  
- 🎨 Selecting elegant typography and matching color tones  
- 🧩 Structuring files and linking pages seamlessly  

Each challenge deepened my understanding of **frontend design principles** and **Bootstrap’s utility classes**.
